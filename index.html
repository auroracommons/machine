About

A neural network library written from first principles using only NumPy. Custom Tensor with reverse-mode automatic differentiation. Dense, Dropout, BatchNorm layers. SGD, Adam, RMSprop optimizers. MSE, Cross-Entropy losses.

Plus an interactive training visualizer powered by Matplotlib so you can watch the loss surface as your network learns.
