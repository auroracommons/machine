Machine

Machine serves autonomy, Layer 5. Here you learn how a neural network works by building one from scratch with only NumPy. You get code you can read, run, and change.

View on GitHub | Documentation

About

The code builds a neural network from basic parts, with only NumPy. A custom Tensor tracks each step so the code can work out gradients on its own. Layers include Dense, Dropout, and BatchNorm. Tools that update the model during training include SGD, Adam, and RMSprop. Ways to measure error include MSE and Cross-Entropy loss.

You can plot training with Matplotlib and watch the loss fall as your network learns.
